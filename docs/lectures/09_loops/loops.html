Repetition Structures

We often need to write code that performs the same task multiple times. There are many possible problems when it comes to duplicating code, most of which center around the increased likelihood of making mistakes. The program becomes larger, the time needed to construct the program becomes longer, mistakes that are noticed early may need to be corrected in many places, etc.

We can ease these issues by using repetition structures, which make the computer repeat a set of code.

Condition-Controlled and Count-Controlled Loops

Repetition structures are generally implemented in what are called loops. There are two broad categories of loops:

  • Condition-controlled which uses a True/False condition to control the number of times the loop iterates

  • Count-controlled which repeats a specific number of times

The for Loop

A for loop is a count-controlled loop. During initialization, it is set to iterate a fixed maximum number of times. We will see later on how we can skip iterations or end the loop prematurely but we can never increase the number of times the loop iterates. This is not much of a limitation as for loops are designed to work with a sequence of data items and so the loop needs to iterate for each item in the sequence.

General format:

for variable in sequence:

    statement
    statement
    ...

We say that the target variable is the variable which is the target of the assignment at the beginning of each iteration. In the code below, the target variable is num.

for num in [1,2,3,4,5]:
    print(num)

Using the range Function With the for Loop

The range function returns an iterable object, which is a type of object that contains a sequence of values that can be stepped through value by value (iterated over).

In the most fundamental case, the range function produces an object that is mapped to the integers 0 to n-1 where n is the ending limit that is specified by the user.

When we think back to indexing of lists and similar structures, this ordering is exactly how we progress from the first element to the last.

The range function has the capacity to alter its progression and this is controlled by the number of arguments passed into the function.

  • One argument: used as ending limit
  • Two arguments: starting value and ending limit
  • Three arguments: third argument is step value

One Argument

for num in range(5):
  print(num)

Letting the User Control the Loop Iterations

Sometimes we do not know exactly how many times the loop will execute. One solution is that, if the user knows how many times the loop needs to run, we can receive range inputs from the user, place them in variables, and call the range function in the for clause using these variables.

Be sure to consider the end cases: range does not include the ending limit.

x = int(input("Input an integer: "))

for i in range(x+1):
    print(i)

Copying Lists

To make a copy of a list you must copy each element of the list. Simply creating a variable that references the original list does not create a copy, the new variable only points to the existing list.

We cannot just use the assignment operator to set one list to another list.

list1 = [1,2,3]
list2 = list1

list2[0] = 5

print(list1)
print(list2)
[5, 2, 3]
[5, 2, 3]

We can see that changing a value what is referenced by list2 is reflected in list1. This is because both variables reference the same object.

To create a true copy of a list we have two main methods:

  • Creating a new empty list and using a for loop to add a copy of each element from the original list to the new list
  • Creating a new empty list and concatenating the old list to the new empty list
list1 = [1,2,3]
list2 = []

for i in list1:
    list2.append(i)

#If we look at the memory locations of these lists, we see that they are different and so the lists themselves are different objects.
print(id(list1))
print(id(list2))
4508228160
4508228224

List Comprehensions

List comprehensions are concise expressions that creates a new list by iterating over the elements of an existing list.

The following code uses a list comprehension to make a copy of a list, just like the above example:

list1 = [1, 2, 3]

list2 = [item for item in list1]

\mathtt{list2 = [} \underbrace{\mathtt{item}}_{\text{Result Expression}} \mathtt{\ } \underbrace{\mathtt{for\ item\ in\ list1}}_{\text{Iteration Expression}} \mathtt{]}

The result expression is the first part of the expression, item, and the iteration expression is the latter part, for item in list1.

The iteration expression works like a for loop. In this example, it iterates over the elements of list1. Each time it iterates, the target variable item is assigned the value of an element. At the end of each iteration, the value of the result expression is appended to the new list.

list1 = [1, 2, 3, 4]
list2 = [item**2 for item in list1]

#After this code executes, list2 will contain the values [1, 4, 9, 16]
print(list2)
[1, 4, 9, 16]
str_list = ['zero', 'one', 'two']
len_list = [len(s) for s in str_list]

#After this code executes, len_list will contain the values [4, 3, 3]
print(len_list)
[4, 3, 3]

You can use an if clause in a list comprehension to select only certain elements when processing a list.

list1 = [1, 12, 2, 20, 3, 15, 4]
list2 = []

for n in list1:
    if n < 10:
        list2.append(n)

print(list2)
[1, 2, 3, 4]

Works the same as

list1 = [1, 12, 2, 20, 3, 15, 4]
list2 = [item for item in list1 if item < 10]

print(list2)
[1, 2, 3, 4]

The while Loop: a Condition-Controlled Loop

A while loop is a condition-controlled loop, where while the condition is true, the loop statement(s) are exectued.

There are two parts to the while loop:

  • Condition tested for true or false value
  • Statements repeated as long as condition is true

The general format is:

while condition:

    statement
    statement
    ...

In order for a while loop to stop executing, something has to happen inside the loop to make the condition false.

While loops in Python are known are pretest loops. This means the condition is tested before performing an iteration. If the condition is false to start with, the loop immediately ends.

values = [1,2,3]

while len(values) !=0:
    print(values.pop())

Infinite Loops

Loops must contain within themselves a way to terminate.With for loops, this was implicit as they had a maximum number of total iterations. But with while loops something needs to make the condition false.

If there is no way to make the condition false, you have an infinite loop, which is a loop that has no way of ending.

n = 0

while n < 10:
    print(n)

Note that there is no change to the value of n in the code above, so the expression n < 10 will always evaluate to True.

To avoid infinite loops there must always be a way to terminate the loop. This usually involves making progress towards turning the initial condition false by adjusting the value being tested.

Here, since we are testing n < 10 if we continually increase the value of n each iteration we will eventually turn this condition false.

n = 0

while n < 10:
    n += 1
    print(n)

Sentinels

A sentinel is a special value that marks the end of a sequence of items. When program reaches a sentinel, it knows that the end of the sequence of items was reached, and the loop terminates.

The sentinel must be distinctive enough so as not to be mistaken for a regular value in the sequence.

In Python, usually sequences are iterated through with for loops which automatically control for the size of the sequence. However, if we are taking in input we may not know how long the input actually is and we need some way of recognizing that the input process is finished. We can use a sentinel for this.

data = []

while value := int(input("Enter a non-negative number or enter -1 to finish: ")) != -1:
    if value < 0:
        print("Enter only non-negative numbers or -1 to finish.")
        continue
    else:
        data.append(value)

This code takes in non-negative numbers into a list called data. Note that the sentinel value is -1 and that any other negative value is ignored. This is an example of input validation. Input validation is a necessary part of programming as the computer cannot tell the difference between good data and bad data inherently.

If a user provides bad input, the program will likely produce bad output. This is the Garbage In, Garbage Out (GIGO) principle. So it is important to design programs in a way that bad input is not accepted. We do this through input validation, where we inspect the input before it is actually processed by the program.

This is common accomplished using a while loop like in the example above. The input process will repeat if the data is bad (usually with some error message displayed).

Using the while Loop as a Count-Controlled Loop

The while loop is inherently a condition-controlled loop. However, you can use the while loop as a count-controlled loop by pairing it with a counter variable.

A counter variable is assigned a unique value during each iteration of a loop and it counts the number of iterations. Once a certain value is reached, the loop will terminate.

A count-controlled while loop must perform three actions:

  • Initialization: The counter variable must be initialized to a suitable starting value before the loop begins.

  • Comparison: The loop must compare the counter variable to a suitable ending value, to determine whether the loop should iterate or not.

  • Update: During each iteration, the loop must update the counter variable with a new value.

n = 0
while n < 5:
    print(n)
    n += 1

Nested loops

A nested loop is a loop that is contained inside another loop.

for i in range(2):      #outer loop
    for j in range(3):  #inner loop
        print(j)
0
1
2
0
1
2

Note that the inner loop goes through all of its iterations for each iteration of outer loop. This implies that inner loops complete their iterations faster than outer loops

The total number of iterations in a nested loop is the number of each loops iterations all multiplied together.

For our example above, the inner loop has 3 iterations and the inner loop runs a total of 2 times, the number of iterations of the outer loop. So, there are 6 overall iterations completed or 2\times3.

values = [1,2,3]

for i in range(3):
    for j in range(2):
        values[i] += j

print(values)
[2, 3, 4]

The else Clause With a Loop

Loops in Python can have an optional else clause.

for variable in sequence:

    statement
    statement
    ...

else:

    statement
    statement

An else clause in a loop will always execute unless the loop contains a break statement. The block of statements that appears after the else clause executes only when the loop terminates normally, without encountering a break statement.

If the loop terminates because of a break statement, the else clause will not execute its block of statements.

for n in range(10):

    if n == 5:
        print('Breaking out of the loop.')
        break

    print(n)

else:
    print(f'After the loop, n is {n}.')
