Heterogenous Data

  • NumPy requires pure, homogeneous numbers.
  • Real data is messy, labeled, and heterogeneous.
  • Remember that if we put a word into a NumPy array, it converts our math to text.
  • We need a solution to intake data, then prepare it for use with libraries that perform calculations (like NumPy).

Pandas

  • Pandas is an industry-standard library for data ingestion and cleaning.

  • Pandas does not replace NumPy; they serve different roles.

    • Pandas prepares the data.
    • NumPy solves the equations.

import pandas as pd

DataFrames

  • The core component of Pandas is the DataFrame.

    • A 2D array (matrix) with attached row and column labels.

  • Each column can hold a different type of data without breaking the others.

  • We load our data using one of the Pandas methods depending on our file type, and Pandas will do the work of figuring out what the datatypes of the individual columns should be.

Filtering Rows (Boolean Masking)

# Apply the mask to the DataFrame

# Do it in one line:

danger_data = df[df[‘Temp’] > 100]

Sorting

  • Sorting data sequentially in Pandas is very simple.

  • .sort_values() orders the matrix by a specific column.

    • The column is specified using the by parameter
    • You can adjust sorting by ascending/descending order by setting the Boolean on the ascending parameter.

# Sort from highest profit to lowest

sorted_data = df.sort_values(by=‘Profit’, ascending=False)

# View the top 3 most profitable rows

print(sorted_data.head(3))

Handling Missing Data

  • NaN stands for “Not a Number” (a blank cell in the CSV).

    • We mentioned other versions earlier like NaT (Not a Time)

  • In general, you cannot do mathematics with missing data.

    • Calculations that involve NaN resolve to NaN.
    • Calculations that involve None throw an exception.

  • .dropna() removes any row containing a NaN.

Handling Missing Data

  • The safest decision is to drop the corrupted observation entirely.
  • There exist methods to interpolate the missing value(s), but these should be used cautiously.

# See how many missing values exist

print(df.isna().sum())

# Drop the corrupted rows permanently

df = df.dropna()

Text Scrubbing

  • Sometimes numbers are accidentally imported as strings because of symbols (e.g., “$1,000”).
  • We use .str to access string methods, and .astype() to cast them back to numbers.

# 1. Replace the comma with nothing

df[‘Cost’] = df[‘Cost’].str.replace(‘,’, ’’)

# 2. Strip accidental blank spaces

df[‘Cost’] = df[‘Cost’].str.strip()

# 3. Convert the clean text back into a float for math

df[‘Cost’] = df[‘Cost’].astype(float)

Time and Dates

  • Python reads dates as “dumb” strings by default.
  • pd.to_datetime() converts them into “smart” timestamps.
  • The .dt accessor extracts specific features (month, year, day of week).

# Convert the string column to datetime objects

df[‘Date’] = pd.to_datetime(df[‘Date_String’])

# Extract the month as a new numeric column (1-12)

df[‘Month’] = df[‘Date’].dt.month

Useful Distinctions

  • Aggregation (sum(), mean(), count()) computes one value per group.

  • Reduction (max(), min()) computes one value from the entire Series.

    • A series can be viewed as a single column in the DataFrame.

  • Index retrieval (idxmax(), idxmin()) tells you which label produced that maximum or minimum.

Performing Mathematics on DataFrames

  • More complicated mathematical operations will require you to cast the DataFrame to a NumPy array.
  • This is done using the .to_numpy() method.
  • Note that there can be no text or NaN values in the columns that are cast into an array if you want to receive valid output.

data = df[‘Sales’].to_numpy()

print(data.mean())

Multiple Aggregations

  • Often, we need different math for different columns at the same time.
  • The .agg() method takes a dictionary: { ‘ColumnName’: ‘math_operation’ }.
  • This can complete enormous tasks in a single computational pass.

#Find the total, average, maximum, and minimum sales by region.

summary = (

df.groupby(‘Region’)[‘Sales’]

.agg([‘sum’, ‘mean’, ‘max’, ‘min’])

)

print(summary)

Reshaping: Melt

  • Human generated data is often “wide” (e.g., Jan, Feb, Mar as separate columns).
  • pd.melt() unpivots data, collapsing multiple columns down into two generic columns: “Variable” and “Value”.
  • Many plotting libraries, statistical tools and SQL databases expect data in the melt format, not the pivot format.

tall_df = pd.melt(

wide_df,

id_vars=[’’], # Columns to lock in place

var_name=’’, # Name for the columns

value_name=’’ # Name for the values

)

Concatenation

  • pd.concat() is used when you have the exact same columns, but new rows of data.
  • Perfect for stacking multiple months, quarters, or batches of data together.
  • Important to reset the index to prevent repeated row numbers.

Merging & Joins

  • Merges and joins are among the most important operations in pandas because they allow you to combine information from multiple DataFrames.

  • The important question when combining two DataFrames is:

  • How do we know which rows belong together?

  • Pandas answers this by matching values in one or more columns.

    • It can also match on an index, which is the term row label.
    • Columns contain the actual data values; the index is just for identification.

Merging & Joins

  • pd.merge() combines two different DataFrames based on a shared column (a “Key”).

    • This is identical to a SQL JOIN.

  • Left Join: Keep everything in the left table, attach data from the right table if it matches.

  • Right Join: Keep everything in the right table, attach data from the left table if it matches.

  • Inner Join: Keep only rows that appear in both tables.

  • Outer Join: Keep everything from both tables.

Merging & Joins

  • The basic syntax is:

pd.merge(left_df, #Left DataFrame

right_df, #Right DataFrame

on=“ColumnName”, #Column used for matching

how=“inner”) #Type of join

Merging on Different Column Names

  • Sometimes the key columns have different names.
  • This is easily handled using the left_on and right_on parameters.

Multi-Key Joins

  • Sometimes one column is not enough to guarantee a unique match.
  • For example, an Account Number might repeat across different Processing Dates.
  • We can pass a list of columns to the on parameter to match on multiple keys simultaneously.

pd.merge(df1,

df2,

on=[“CustomerID”, “Type”])

Concatenation is Different from Merging

  • A common mistake is confusing merge() with concat().

  • concat() stacks DataFrames together.

    • It does not match rows.

  • If you need to match rows, use merge() and specify the type of join.

    • If you want to match by the index (and not the data in the column) use the join() method instead.
    • Matching by index is uncommon, most situations will be by matching columns.

  • If you do not need to match rows, use concat().
