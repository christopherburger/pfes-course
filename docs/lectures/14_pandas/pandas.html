14: Pandas

Pandas

We have seen that NumPy requires pure, homogeneous numbers. Remember that if we put a word into a NumPy array, it converts our numbers to text. But real data is messy, labeled, and heterogeneous.

We need a solution to intake data, then prepare it for use with libraries that perform calculations (like NumPy). This solution is Pandas, which is an industry-standard library for data ingestion and cleaning.

Pandas does not replace NumPy; they serve different roles.

  • Pandas prepares the data.

  • NumPy performs mathematics.

As Pandas is an external library, we will need to import it to use it (and depending on your environment, it may need to be installed first).

import pandas as pd

DataFrames

The core component of Pandas is the DataFrame which is a 2D array (a matrix) with attached row and column labels. Each column can hold a different type of data without breaking the others.

We load our data using one of the Pandas methods depending on our file type, and Pandas will do the work of figuring out what the datatypes of the individual columns should be.

Loading Data

To load data into a DataFrame, we first need to know what file type we are working with. Commonly, this is a CSV file (Comma Separated Values)

We then need to know where the file is located. This could be a file path on your computer or even a URL.

import pandas as pd

url = "https://website/data.csv"

df = pd.read_csv(url)

For many of our examples we will use a CSV file (Tableau’s Sample Superstore dataset) that can be found on Blackboard. Assuming we have named the file superstore.csv we can use the following code to load the data into a DataFrame named df.

import pandas as pd

df = pd.read_csv('superstore.csv')

Renaming Columns

Raw data often has terrible names (e.g., “Temp (C) - Sensor 1!”). We can use .rename() and a dictionary to fix them before writing any code that involves them.

The syntax is: columns={'old_name': 'new_name’}

For example: df = df.rename(columns={'Discount': 'Proportional Discount'})

Filtering Rows (Boolean Masking)

We can apply the exact same relational logic we have seen and used before (>, <, ==) to a Pandas column. This creates a “mask” of True/False values to filter the DataFrame.

#Find all rows where the discount is greater than 20%
discount_mask = df['Discount'] > 0.2

#Apply the mask to the DataFrame
discount_data = df[discount_mask]

We can also do this all in a single line:

discount_data = df[df['Discount'] > 0.2]

Handling Missing Data

NaN stands for “Not a Number” (a blank cell in the CSV). We mentioned other versions earlier like NaT (Not a Time)

In general, you cannot do mathematics with missing data.

  • Calculations that involve NaN resolve to NaN.
  • Calculations that involve None throw an exception.

.dropna() removes any row containing a NaN.

The safest decision is to drop the corrupted observation entirely.

There exist methods to interpolate the missing value(s), but these should be used cautiously.

# See how many missing values exist
print(df.isna().sum())

# Drop the corrupted rows permanently
df = df.dropna()

Text Scrubbing

Sometimes numbers are accidentally imported as strings because of symbols (e.g., “$1,000”).

We use .str to access string methods, and .astype() to cast them back to numbers.

1. Replace the comma with nothing

df['Cost'] = df['Cost'].str.replace(',', '')

2. Strip accidental blank spaces

df['Cost'] = df['Cost'].str.strip()

3. Convert the clean text back into a float for math

df['Cost'] = df['Cost'].astype(float)

Time and Dates

Python reads dates as “dumb” strings by default. pd.to_datetime() converts them into “smart” timestamps. The .dt accessor extracts specific features. (month, year, day of week).

1. Convert the string column to datetime objects

df['Date'] = pd.to_datetime(df['Date_String'])

2. Extract the month as a new numeric column (1-12)

df['Month'] = df['Date'].dt.month `

Aggregation

How do we find the average profit per day?

Or the postal code with the highest number of total sales?

We can use the groupby() method, likely the most powerful single tool in Pandas.

The process has three steps:

  1. Split the data into categories.
  2. Apply math.
  3. Combine the results.
# Drop rows where the date column is NaT

df = df.dropna(subset=['Order Date'])

appd = df.groupby('Order Date')['Profit'].mean() #average profit per day

Useful Distinctions

Aggregation (sum(), mean(), count()) computes one value per group.

Reduction (max(), min()) computes one value from the entire Series.

  • A series can be viewed as a single column in the DataFrame.

Index retrieval (idxmax(), idxmin()) tells you which label produced that maximum or minimum.

Performing Mathematics on DataFrames

More complicated mathematical operations will require you to cast the DataFrame to a NumPy array. This is done using the .to_numpy() method.

Note that there can be no text or NaN values in the columns that are cast into an array if you want to receive valid output.

data = df['Sales'].to_numpy()

print(data.mean())
229.21681761995393

Simple operations can be done on the DataFrame itself, especially a single series associated with it.

print(df["Sales"].mean())
229.21681761995393

We can also iterate through using the standard Python for loop syntax. However, Pandas specific operations are both shorter to write and more efficient.

#Also the mean of the sales series

s = 0

for i in df['Sales']:
    s += i
print(s/len(df['Sales']))
229.21681761994947

Multiple Aggregations

Often, we need different math for different columns at the same time. The .agg() method takes a dictionary: { 'ColumnName': 'math_operation' }.

This can complete enormous tasks in a single computational pass.

#Find the total, average, maximum, and minimum sales by region.

summary = (df.groupby('Region')['Sales'].agg(['sum', 'mean', 'max', 'min']))

def range(series):

Concatenation

pd.concat() is used when you have the exact same columns, but new rows of data. This works well for stacking multiple months, quarters, or batches of data together.

Note that it is important to reset the index to prevent repeated row numbers.

# Stacking Q1 and Q2 data vertically

full_year_df = pd.concat([q1_data, q2_data], axis=0)


#Reset the index so row numbers don't repeat

full_year_df = full_year_df.reset_index(drop=True)

Merging & Joins

Merges and joins are among the most important operations in pandas because they allow you to combine information from multiple DataFrames.

The important question when combining two DataFrames is: How do we know which rows belong together?

Pandas answers this by matching values in one or more columns. It can also match on an index, which is the term row label. Columns contain the actual data values; the index is just for identification.

pd.merge() combines two different DataFrames based on a shared column (a “Key”). This is identical to a SQL JOIN.

  • Left Join: Keep everything in the left table, attach data from the right table if it matches.

  • Right Join: Keep everything in the right table, attach data from the left table if it matches.

  • Inner Join: Keep only rows that appear in both tables.

  • Outer Join: Keep everything from both tables.

The basic syntax is:

pd.merge(left_df, #Left DataFrame

right_df, #Right DataFrame

on="ColumnName", #Column used for matching

how="inner") #Type of join

Suppose we have two DataFrames, customers and accounts.

customers = {
    'CustomerID':[101,102,103,104],
    'Name': ['Alice', 'Bob', 'Charlie', 'David']
}

customers = pd.DataFrame(customers)

accounts = {
    'CustomerID':[101,101,103,105],
    'Name': ['2500', '1200', '8000', '500']
}

accounts = pd.DataFrame(accounts)

Inner Join

An inner join keeps only rows that appear in both tables.

merged = pd.merge(customers, accounts, on="CustomerID", how="inner")

print(merged)
   CustomerID   Name_x Name_y
0         101    Alice   2500
1         101    Alice   1200
2         103  Charlie   8000

Notice that Alice appears twice. This is because there are two matching rows in the Accounts table. Inner join is matching every possible pair.

Left Join

A left join keeps everything from the left table.

merged = pd.merge(customers, accounts, on="CustomerID", how="left")

print(merged)
   CustomerID   Name_x Name_y
0         101    Alice   2500
1         101    Alice   1200
2         102      Bob    NaN
3         103  Charlie   8000
4         104    David    NaN

Since Bob and David have no entry in the right table (accounts) Pandas will insert NaN to fill the empty balance value.

Right Join

A right join keeps everything from the right table.

merged = pd.merge(customers, accounts, on="CustomerID", how="right")

print(merged)
   CustomerID   Name_x Name_y
0         101    Alice   2500
1         101    Alice   1200
2         103  Charlie   8000
3         105      NaN    500

Note that customer 105 only exists in the accounts table; Pandas will insert NaN to fill the empty name value.

Outer Join

An outer join keeps everything from both tables.

merged = pd.merge(customers, accounts, on="CustomerID", how="outer")

print(merged)
   CustomerID   Name_x Name_y
0         101    Alice   2500
1         101    Alice   1200
2         102      Bob    NaN
3         103  Charlie   8000
4         104    David    NaN
5         105      NaN    500

Notice that nothing in either table is discarded.

Merging on Different Column Names

  • Sometimes the key columns have different names.
  • This is easily handled using the left_on and right_on parameters.
pd.merge(customers, transactions, left_on="CustomerID", right_on="CustID")

Multi-Key Joins

Sometimes one column is not enough to guarantee a unique match.

For example, an Account Number might repeat across different Processing Dates. We can pass a list of columns to the on parameter to match on multiple keys simultaneously.

pd.merge(df1, df2, on=["CustomerID", "Type"])

Concatenation is Different from Merging

A common mistake is confusing merge() with concat().

concat() stacks DataFrames together, it does not match rows. If you need to match rows, use merge() and specify the type of join.

If you want to match by the index (and not the data in the column) use the join() method instead. Matching by index is uncommon, most situations will be by matching columns.

If you do not need to match rows, use concat().
