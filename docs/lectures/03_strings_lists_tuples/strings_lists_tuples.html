3: Lists, Strings and Tuples

Lists

In Python, variables can store more than a single piece of information. These are multidimensional variables. We have already seen an example of a multidimensional variable, the string data type. Recall that a string is a sequence of characters and that each character in the sequence can be accessed independently from any other character.

The most common general purpose multidimensional variable in Python is the list.

Lists are ordered collections of values.

  • Duplicates are allowed.
  • You may have different types of data present in a single list.

We use the order built into a list to access and alter the different values.

Creating a List

  • Lists are created using the square brackets [ ]
  • Separate multiple items in a list using a comma.
A_List = [ ] #This is an empty list

B_List = [ 1 , 2 ] #This list contains integers 1 and 2

Accessing Elements in a List

Items within a list are often referred to as elements.

Use the square brackets [ ] after the name of the list to reference the location of the desired element.

Note that Python starts counting elements from zero, not from one. Therefore the first element in a list is located at index zero.

C_List = [ 'x' , 'y' , 'z' ]

print(f'First element: {C_List[0]}')
First element: x
print(f'Second element: {C_List[1]}')
Second element: y
print(f'Third element: {C_List[2]}')
Third element: z

Python also has the ability to access elements using negative indices where -1 is shorthand for the last element of the list. As such, -2 is the second to last element, -3 the third to last element and so on.

print(f'Last element: {C_List[-1]}')
Last element: z

Adding Elements to a List

Adding new elements to a list in Python is often accomplished using two methods.

The insert function adds an item to a specific index (location).

  • Format: insert(index,value)
C_List = [ 'x' , 'y' , 'z' ]

C_List.insert(0,'a')

print(C_List)
['a', 'x', 'y', 'z']

The append function adds an item directly to the end of the list. Adding an item to the end of a list is a very common operation, so it was given its own dedicated function.

  • Format: append(value)
C_List = [ 'x' , 'y' , 'z' ]

C_List.append('a')

print(C_List)
['x', 'y', 'z', 'a']
  • Define a list called items that contains the letters a, b, c, and d.
  • Add the number 1 at index 2 of items.
  • Add the number 7 at the end of items.
  • Print the list items.

Removing Elements from a List

Removing elements from a list can be accomplished by using the pop() method.

The pop method can be used in two different ways.

  • Removing an element at a specified index.

    • pop(index)

  • Removing an element at the end of the list.

    • pop()

By omitting the index from the pop method, Python automatically assumes you want to remove the last item in the list.

C_List = [ 'x' , 'y' , 'z' ]

C_List.pop(0)

print(C_List)
['y', 'z']
C_List = [ 'x' , 'y' , 'z' ]

C_List.pop()

print(C_List)
['x', 'y']

  • Define a list called items that contains the letters a, b, c, and d.

  • Remove letter b from items.

  • Remove the last letter from items.

  • Print the list items.

Removing elements from a list can also be accomplished by using the del keyword.

The del operation removes an element at a specified index.

  • del list[index]
data = [1, 2, 3]

del data[0]
print(data)
[2, 3]

Unlike pop(), del does not return the item that was removed.

Note that the del operation uses the square brackets instead of the parenthesis.

The del operation can also be used to completely delete a list.

  • del my_list
data = [1, 2, 3]

del(data)
print(data) #Attemping to reference data will throw an exception as it is no longer defined.

Calculating the Length of a List

A common operation in programming is calculating the number of elements in a list.

In Python this is termed the length of a list.

Python has a built-in function to calculate a list’s length

  • len(list)

This function returns the number of total elements as an integer.

data = ["a", "b", "c", "d"]
print(len(data))
4

List Slicing

A slice is a span of items that are taken from a sequence like a list.

  • Format: list[start : end]

A span is a subset of a sequence containing copies of elements from start up to, but not including, end.

  • If start not specified, 0 is used for start index
  • If end not specified, len(list) is used for end index
data = ["a", "b", "c", "d","e"]
new_data = data[1:3]
print(new_data)
['b', 'c']

Slicing expressions can include a step value and negative indexes relative to end of list.

Strings and String Literals

Recall that a string is sequence of characters that is one of Python’s fundamental data types.

For example, name = input(“Enter a name”) the variable name is a string.

You might see the term string literal used, which is a string that appears in actual code of a program in contrast to the data type.

In the above example “Enter a name” is a string literal.

Often, the term literal is omitted and the word string is used both for the data type and actual character sequence. It is usually easy enough with context to distinguish between the two.

String Concatenation

String concatenation is the process of appending one string to another string.

We can use the + operator to concatenate strings.

message = 'Hello ' + 'world'

print(message)
Hello world

We can use string concatenation to break up a long string literal. This is especially useful if you are writing code on a device with limited screen width.

print('Enter the amount of ' +

'sales for each day and ' +

'press Enter.')
Enter the amount of sales for each day and press Enter.

Notice how this statement is printed all on a single line.

Strings Are Immutable

Strings are immutable. Once they are created, they cannot be changed

Under the surface, concatenation does not change the existing string, but rather creates a new string and assigns it to the previously used variable.

As a consequence of immutability, we cannot use an expression of the form: string[index] = new_character . A statement like this that attempts to overwrite a part of the string will result in an error.

Displaying Formatted Output With f-Strings

An f-string (formatted string literal) is a special type of string literal that is prefixed with the letter f. These are often used to make customization and formatting of the printed output an easier process.

print(f'Hello world')
Hello world

One of the most useful features of f-strings is that they support placeholders for variables.

name = 'Johnny'

print(f'Hello {name}.')
Hello Johnny.

Placeholders can also be expressions that are evaluated.

print(f'The value is {10 + 2}.')
The value is 12.
val = 10

print(f'The value is {val + 2}.')
The value is 12.

Format specifiers can be used to add additional formatting that controls things like the number of decimal places displayed or to what precision a number is rounded.

num = 123.456789

print(f'{num:.2f}')
123.46

  • 2f means:

    • round the value to 2 decimal places
    • display the value as a floating-point number

  • Percentages

discount = 0.5

print(f'{discount:.0%}')
50%
  • Scientific Notation
num = 12345.6789

print(f'{num:.2e}')
1.23e+04

When using multiple designators in a format specifier, the order is as follows: [alignment][width][,][.precision][type]

  • Example: print(f'{number:^10,.2f}')

There are many other options and ways of formatting strings in Python. The office reference material at https://docs.python.org/3/tutorial/inputoutput.html contains extensive details.

String Methods

Strings in Python have many types of methods, divided into different types of operations.

  • General format: mystring.method(arguments)

Some methods test a string for specific characteristics. These are generally Boolean methods in that they return True if a condition exists, and False otherwise.

Some String Testing Methods

Method Description
isalnum() Returns true if the string contains only alphabetic letters or digits and is at least one character in length. Returns false otherwise.
isalpha() Returns true if the string contains only alphabetic letters and is at least one character in length. Returns false otherwise.
isdigit() Returns true if the string contains only numeric digits and is at least one character in length. Returns false otherwise.
islower() Returns true if all of the alphabetic letters in the string are lowercase, and the string contains at least one alphabetic letter. Returns false otherwise.
isspace() Returns true if the string contains only whitespace characters and is at least one character in length. Returns false otherwise. (Whitespace characters are spaces, newlines (\n), and tabs (\t).
isupper() Returns true if all of the alphabetic letters in the string are uppercase, and the string contains at least one alphabetic letter. Returns false otherwise.

Some methods return a copy of the string, to which modifications have been made. These simulate strings as mutable objects.

Note that string comparisons are case-sensitive.

  • Uppercase characters are distinguished from lowercase characters

  • lower and upper methods can be used for making case-insensitive string comparisons

Some String Modification Methods

Method Description
lower() Returns a copy of the string with all alphabetic letters converted to lowercase. Any character that is already lowercase, or is not an alphabetic letter, is unchanged.
lstrip() Returns a copy of the string with all leading whitespace characters removed. Leading whitespace characters are spaces, newlines (\n), and tabs (\t) that appear at the beginning of the string.
lstrip(char) The char argument is a string containing a character. Returns a copy of the string with all instances of char that appear at the beginning of the string removed.
rstrip() Returns a copy of the string with all trailing whitespace characters removed. Trailing whitespace characters are spaces, newlines(\n), and tabs (\t) that appear at the end of the string.
rstrip(char) The char argument is a string containing a character. The method returns a copy of the string with all instances of char that appear at the end of the string removed.
strip() Returns a copy of the string with all leading and trailing whitespace characters removed.
strip(char) Returns a copy of the string with all instances of char that appear at the beginning and the end of the string removed.
upper() Returns a copy of the string with all alphabetic letters converted to uppercase. Any character that is already uppercase, or is not an alphabetic letter, is unchanged.

Programs commonly need to search for substrings, a smaller component of a string.

There are several methods to accomplish this:

Some Search and Replace Methods

Method Description
endswith(substring) The substring argument is a string. The method returns True if the string ends with substring.
find (substring) The substring argument is a string. The method returns the lowest index in the string where substring is found. If substring is not found, the method returns negative 1
replace(old, new) The old and new arguments are both strings. The method returns a copy of the string with all instances of old replaced by new.
startswith (substring) The substring argument is a string. The method returns True if the string starts with substring.

The Repetition Operator

The repetition operator * makes multiple copies of a string and joins them together. This is only applicable when the operands are a string (on the left) and an integer (on the right).

General format: string_to_copy * n

The output references a new string which contains multiple copies of the original string.

String Tokens

Sometimes a string contains substrings that are separated by a special character.

  • Example: 'peach raspberry strawberry vanilla'

This example contains the substrings peach, raspberry, strawberry, and vanilla if we choose the space to be our separator.

The substrings are separated by the space character and the substrings are known as tokens with separating character being the delimiter

  • The string '17;92;81;12;46;5' contains the tokens 17, 92, 81, 12, 46, and 5 if we choose the delimiter to be the ; character.

Tokenizing is the process of breaking a string into tokens. When you tokenize a string, you extract the tokens and store them as individual items.

In Python you can use the split method to tokenize a string.

Splitting a String

The split method returns a list containing the tokens in the string.

By default, the split method uses the space as separator to define what these tokens are. We can specify a different separator by passing it as an argument to the split method.

str = 'peach raspberry strawberry vanilla'

tokens = str.split()

print(tokens)
['peach', 'raspberry', 'strawberry', 'vanilla']
my_address = 'www.example.com'

tokens = my_address.split('.')

print(tokens)
['www', 'example', 'com']
my_string = '1/2/3/4/5'

number_list = my_string.split('/')

print(number_list)
['1', '2', '3', '4', '5']

Tuples

A tuple is an immutable sequence.

Similar to a list in that it is ordered and can hold multiple objects of different types. But once a tuple is created new elements cannot be added to the tuple and existing elements cannot be removed from the tuple.

Creating a tuple is just like creating a list except we use parenthesis instead of square brackets.

  • Format: my_tuple= (item1, item2)
data = ("a", "b", "c")
print(type(data))
<class 'tuple'>

Note that since a tuple is immutable, once it is created it cannot be altered. You need to specify all the items you want inside the tuple at the time of its creation.

Tuples support many list operations:

  • Subscript indexing for retrieving elements
  • Methods such as index
  • Built in functions such as len, min, max
  • Slicing expressions
  • The in, +, and * operators (the latter two operators create new tuples)

We can also convert back and forth from lists to tuples. This can be useful when we need to adjust the values within a tuple.

  • list() function: converts tuple to a list

  • tuple() function: converts list to a tuple

Since tuples are immutable they do not support the methods:

  • append
  • remove
  • insert
  • reverse
  • sort

Why use tuples at all if they are more restrictive than lists?

  • Processing tuples is faster than processing lists
  • Tuples provide safety:
    • no elements can be added to or deleted from a tuple
    • once a tuple is created, the elements of the tuple will always refer to the same objects
  • Some operations in Python require use of tuples

Storing Mutable Objects in a Tuple

Although tuples are immutable, you can store mutable objects in a tuple. This is one of the stranger aspects of Python.

For example, the following statement creates a tuple that contains a list as its 3rd element: t = (10, 20, [97, 98, 99])

When a tuple element refers to a mutable object, that object’s data can be changed.

t = (10, 20, [97, 98, 99])

print(t)
(10, 20, [97, 98, 99])
 t[2].append(100) # Since the list inside the tuple t is mutable, we can change parts of the list.

 print(t)
(10, 20, [97, 98, 99, 100])

So, we can change the values inside the list that is within the tuple (because the list is mutable) but we cannot change the location of the list (or any other elements) in the tuple since those are immutable.
