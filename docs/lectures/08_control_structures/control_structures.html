8: Control Structures

Control Structures

A control structure is a logical design that controls the order in which a set of statements executes.

So far, we have been dealing with what is known as a sequence structure, where our set of statements executes in the order they appear. What we will learn now is how to implement decision (or selection) structures, where specific action(s) are performed only if some condition exists.

The if Statement

The if statement is the fundamental statement when it comes to creating a decision structure in Python (and in most other languages). It is a single alternative decision. Action(s) are performed should the condition be True and the program continues on the same after the block regardless of state of the condition.

General Format:

if condition:

    Statement

    Statement

    ...

The first line is known as the if clause. This is the keyword if followed by the condition that needs to be True for the statement(s) below to be executed. If the condition is False then all the statements inside the block are skipped.

x = 6

if x > 5:
    print(f'The value of x is: {x}')
    print("x is greater than five")

print("Continuing on...")   
The value of x is: 6
x is greater than five
Continuing on...
x = 5

if x > 5:
    print(f'The value of x is: {x}')
    print("x is greater than five")  

print("Continuing on...")   
Continuing on...

Note that the statements must be indented inside the block. If left on the same level, you will have a syntax error, or worse, they will be evaluated after the block ends.

x = 5

if x > 5:
    print(f'The value of x is: {x}')
print("x is greater than five")

print("Continuing on...")   
x is greater than five
Continuing on...

The example above is missing the indent on the second print statement and so what is printed to the console is not reflective of what the value of x actually is.

Single-Line if Statements

An if statement can be written on a single line if it executes only one statement.

score = 70

if score > 60: print('You passed!')
You passed!

Multiple statements require you to use the standard if structure.

The if-else Statement

The if-else statement is a dual alternative decision structure. Now, there are two possible paths of execution, one path is taken if the condition is Trueand the second path if the condition is False.

Note that the if clause and else clause must be aligned and that all the statements must be consistently indented.

x = 5

if x > 5:
    print("x is greater than five")
else:
    print("x is not greater than five")
x is not greater than five

Conditional Expressions

A conditional expression is a terse way of performing a conditional assignment on a single line.

The general format is:

value_1 if condition else value_2

  • condition is a Boolean expression that is tested

  • If condition is True, the expression gives us value_1

  • If condition is False, the expression gives us value_2

The following conditional expression reads: if score is greater than 59, grade is assigned ‘Pass’. Otherwise, grade is assigned ‘Fail’.

score = 50

grade = 'Pass' if score > 59 else 'Fail'

print(grade)
Fail

Which is equivalent to:

score = 50

if score > 59:
    grade = 'Pass'
else:
    grade = 'Fail'

print(grade)
Fail

Nested and Compound Decision Structures

Often we need to test multiple simultaneous conditions.

For example, we need to determine if someone qualifies for a loan and they must meet two conditions:

  • Must earn at least $30,000/year
  • Must have been employed for at least two years

We have to approaches here, we can use a compound Boolean expression:

if income >= 30000 and length_employment >= 2:
    print('Qualified')

Where the and operator enforces that both expressions must be True for the overall expression to be True.

Or, we can nest a decision structure inside of another:

if income >= 30000:
    if length_employment >= 2:
        print('Qualified')

We check the first (outer) condition to see if it is True, and if so, we then move inside the first statement and now test the second condition (the inner condition) to see if it is True.

Note that it is very important to use proper indentation in a nested decision structure. It can be easy to write code that is syntax-correct, but logically invalid due to misplaced indentation.

The if-elif-else Statement

The logic of many nested decision structures can be difficult to implement without error. Python has a special statement that makes writing nested decision structures simpler.

The if-elif-else statement links multiple if statements together in a chain of exclusive conditions.

x = 5

if x > 5:
    print("x is greater than five")
elif x < 5:
    print("x is less than five")
else:
    print("x is equal to five")
x is equal to five

Note that the if, elif, and else clauses are all aligned and conditionally executed blocks are consistently indented.

An if-elif-else statement is never required, but the logic is often easier to write and to follow.

Consider the previous example converted into a purely nested decision structure using standard if-else statements.

x = 5

if x > 5:
    print("x is greater than five")
else:
    if x < 5:
        print("x is less than five")
    else:
        if x == 5:
            print("x is equal to five")
x is equal to five

This code accomplishes the same thing, but is more prone to error due to its increased size and complexity.

Assignment Expressions and the Walrus Operator

The walrus operator := is a combination operator that assigns a value to a variable and returns the value that was assigned to the variable. These are known as assignment expressions.

print(num := 99)
99

This statement does two things:

  • It assigns 99 to the num variable
  • It prints the value that was assigned to the num variable, 99

Importantly, num now exists as a variable and can be referred to in future sections of code.

if (area := width * height) > 100:
    print('The area is too large')

This statement does the following:

  • The area variable is assigned the value of width * height
  • If the value that was assigned to area is greater than 100, the message The area is too large is displayed.

Note that an assignment expression is not a complete statement. All of our examples used the assignment expression as a component of some other statement. This is a requirement in Python as an assignment expression alone will cause an error:

num := 15

The code above is invalid, and the expression must be written as part of a larger statement like

print(num:= 15)

Precedence of the walrus operator

The walrus operator has the lowest precedence of all the operators in Python.

When using the walrus operator in a larger expression that also uses other operators, the walrus operator will work last. This means in most cases, you need to put parentheses around the assignment expression to make sure the walrus operator assigns the correct value to its variable
