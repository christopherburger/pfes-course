13: Exceptions and Files

Introduction to File Input and Output

For a program to retain data between the times it is run, you must save the data. Data is saved to a file and then data can be retrieved and used at a later time.

The process of saving data to a file is often called writing and the file the data is saved to is the output file. To retrieve the data, we read from an input file.

File Input and Ouput can be summarized in three steps:

  • Open the file

  • Process the file

  • Close the file

Types of Files

Data is stored in many formats, but in most cases we are concerned with two major types of files:

  • Text file: contains data that has been encoded as text (human readable).
  • Binary file: contains data that has been encoded in binary (not human readable).

To simplify testing our code, we will focus almost entirely on text files for our discussion on File Input and Output.

The filename extension is a short sequence of characters that appear at the end of a filename preceded by a period. The extension indicates the type of data stored in the file.

  • The .txt extension indicates a text file.

  • There are many extension names for binary files, but a common one is .bin.

File Access Methods

There are two primary ways to access data stored in file:

  • Sequential access: the file read sequentially from beginning to end and we cannot skip ahead
  • Direct access: we can jump directly to any piece of data in the file

File Objects

In Python the file object is the object associated with a specific file. Multiple files can be active at the same type and the file objects will each hold their respective file’s data. This object is referenced by a variable and we can use specific methods related to files to help read and write data to it.

Opening a File

Our first step is always opening a file. The open function creates a file object and associates it with that specific file.

General format: file_object= open(filename, mode)

The mode is a string that specifies for what purpose the file will be opened. There are three major operations when it comes to files:

  • Reading (‘r’)

  • Writing (‘w’)

  • Appending (‘a’)

Specifying the Location of a File

If the open function receives a filename that does not contain a filepath, Python will assume that the file is in the same directory as the program. Mistyping the location is a common source of errors.

If the program is running and a file is created, it is created by default in the same directory as the program. We can specify an alternative path and file name in the open function argument.

Writing Data to a File

We use a file object’s write method used to write data to the file.

Format: file_variable.write(string)

When we are done writing, we need to close the file object using its close method.

Format: file_variable.close()

Concatenating a Newline to and Stripping it From a String

In most cases, data items written to a file are values referenced by variables. But all data that will be written to a standard text file needs to be in string format. But even with data that is in string format it is often needed to concatenate a \n to data before writing it. Remember that this is the newline character and so is used to place each piece of data on its own separate line.

Similarly, we often need to remove the newline from a string after it is read from the file. We can do this easily using the string processing methods we learned earlier. Specifically, we can use the rstrip method to strip the newline character from the end of the string.

#This writes Line 1, Line 2, … to the file.

file = open("example.txt", "w")

for i in range(1, 6):
    file.write(f"Line {i}\n")

file.close()

Reading Data From a File

We have to primary methods when it comes to reading data from a file.

The first is the read method, which reads the entire file contents into memory. This only works if the file has been opened for reading and all the contents are returned as a single string. In general, this is cumbersome as you will need to process the large string containing the entire contents of the file to separate out the information you are interested in.

The second method is the readline method, which reads line by line from a file object and returns the contents of each line as a string. Note that the newline character will be present. The readline method uses an empty string as a sentinel when end of file is reached. Using readline is done with a while loop with the format: while line != ''.

file = open("example.txt", "r")

while (line := file.readline()) != "":
    print(line)
file.close()

File Pointers

Python keeps track of the current location we are at in the file using a file pointer. When the file is opened, the file pointer is set to the beginning of the file. In our example above we then use the readline method, this reads characters until a newline is encountered. Calling the readline method again advances the file pointer to the next newline, and so on until we reach the end of the file (signified by the empty string).

We have the capability to move the file pointer ourselves using the seek method. For example, seek(0) moves the file pointer to the start of the file. This can be very useful when it comes to opening files for both reading and writing which we will see later on.

Using Python’s for Loop to Read Lines

In practice, we tend to use for loops to iterate through a file automatically. Python is structured that we can use simple syntax to start automatically at the beginning of the file and progress line by line to the end.

Format:

for line in file_object:
    statement
    statement
    ...

for loop syntax automatically pulls each line from our file (line is just the target variable for the for loop). Note that the rstrip here prevents us from having two newlines (there is one implicitly associated with print and rstrip removes the one that was added in the writing process).

file = open("example.txt", "r")

for line in file:
    print(line.rstrip('\n'))

file.close()

Read from the file numbers.txt and add one to each number before it is printed.

    print(int(line.rstrip('\n'))+1)

Appending Data to an Existing File

When we open a file with w mode, if the file already exists it is overwritten. All data within the file is erased and we start from an empty file.

If we want to keep data that is already in a file, we can append it using the a mode. All data written is written to the current end of the file.

#This example writes Line 1, Line 2, … etc to an existing file and places the new content after any existing content.


file = open("example.txt", "a")

    for i in range(1, 6):
        file.write(f"Line {i}\n")

file.close()

Combining Reading and Writing

We are not restricted to a single mode when opening a file. Python allows us the option to open files with the capacity to perform multiple tasks.

The + symbol adds reading or writing to a file mode.

  • ‘r+’ → read and write

    • File must already exist
    • File pointer starts at the beginning
    • Writing happens at the current file position
    • Writing will still overwrite existing content

  • ‘w+’ → write and read

    • Deletes all existing contents when the file is opened
    • If the file does not exist, it is created
    • File pointer starts at the beginning

  • ‘a+’ → append and read

    • File is created if it does not exist
    • File pointer starts at the end
    • Writing always adds to the end
    • Reading requires moving the file pointer manually
file = open("data.txt", “a+")

for i in range(1, 6):
    file.write(f"Line {i}\n")

for line in file:
    print(line.rstrip('\n'))

file.close()

In the example above we initial write lines to a file data. The file pointer is now at the end of the file.

We then attempt to read from the file, but as the file pointer is at the end, the read loop starts at the end and so nothing is printed.

Note that this is not an error, it is expected behavior. We can only read what the file point passes over.

We can alter our example here to move the file pointer back to the beginning so we can read the file we have just written.

file = open("example.txt", “a+")

for i in range(1, 6):
    file.write(f"Line {i}\n")

file.seek(0)

for line in file:
    print(line.rstrip('\n'))

file.close()

Using the with Statement to Open Files

The with statement can be used to open a file and automatically close the file.

General format:

with open(filename, mode) as file_variable:
    statement
    statement
    ...
  • filename is a string specifying the name of the file
  • mode is a string specifying the mode, such as ‘r’, ‘w’, or ‘a’
  • file_variable is the name of the variable that will reference the file object
  • The indented block of statements is known as the with suite
with open("example.txt", "w") as file:

for i in range(1, 6):
    file.write(f"Line {i}\n")

Opening Multiple Files

We can open multiple files at the same time and the with keyword becomes very useful (but not required) as we can avoid keeping track of when and if our possibly many different files are closed.

This example opens two files for the purpose of copying the data from the first file (file1) to the second file (file2).

with open('file1.txt', 'r') as input_file, open('file2.txt', 'w') as output_file:

for line in input_file:
    output_file.write(line)

Exception Handing

Exceptions are errors that occur while a program is running. The default behavior in Python to halt the program and provide a traceback which is an error message that gives brief information regarding the exception like its type and the line numbers that originated the error.

While many exceptions can be prevented by careful coding (we have seen this with input validation) some exceptions cannot like attempting to open a file that does not exist.

For situations where we cannot prevent an exception from occurring, we can write an exception handler, which is a segment of code that responds when exception(s) are raised and prevents the program from halting.

In Python this is written as a try/except suite where the general format is:

try:

    statement
    statement
    ...

except exceptionName:

    statement
    statement
    ...

The try block contains statements that can potentially raise an exception. If an exception is raised in the try block then execution proceeds immediately to the except block (the handler). If the handler can process the type of exception that occurred, the statements in the except block are executed and the program continues to run. Otherwise the program halts as it normally would.

If the statements in the try block do not raise an exception, the statements in the handler are ignored and the program continues on as normal.

Displaying an Exception’s Default Error Message

An exception object is an object created in memory when an exception is thrown. It usually contains a default error message pertaining to the exception.

We can assign the exception object to a variable in an except clause using the following format: except ErrorType as name:

We can also pass the exception object variable to print function to display the default error message.

try:
    print(variable)

except NameError as e:
    print(e)
    print("Continuing on")

Given the list [1,2,’3’,4,’5’,6], use a for loop to attempt to add each element into an accumulator variable.

Use exception handling (use TypeError as the exception type) to ignore errors for undefined operations.

var = [1,2,'3',4,'5',6]
s = 0

for i in var:

        s += i
    except TypeError as e:

print(s)

Handling Multiple Exceptions

Often the code in the try suite can throw more than one type of exception. We can write multiple except clauses, one for each type of exception that needs to be handled.

In this example we can catch two specific errors, a ValueError where the input is not a number and a ZeroDivisionError where the input is a zero. Each error is handled separately.

try:

    num = int(input())
    result = 10 / num
    print(result)

except ValueError:
    print(”Invalid Number.")

except ZeroDivisionError:
    print(”Zero Division.")

Note that an except clause that does not list a specific exception will handle any exception that is raised in the try suite. This may sound advantageous as it reduces the amount of code that needs to be written but can cause problems in the future when debugging as any exception will be caught (including ones you did not anticipate). Your program will continue to run after that step but there may be substantial corruption of things that come afterwards due to unintended behavior.

It is generally considered bad form to have a catch-all exception block. Instead, you should only handle exceptions that you anticipate on occurring. This will allow you to properly debug errors that you did not anticipate.

This example handles all exceptions but the lack of exception type removes useful information as to what went wrong.

try:
    num = int(input())
    result = 10 / num
    print(result)

except:
    print("An error occurred.")

The else Clause

A try/except statement may include an optional else clause, which appears after all the except clauses. The syntax and purpose is similar to an else clause in a decision structure.

The else suite is a block of statements executed after statements in try suite but only if no exceptions were raised. If an exception was raised, the else suite is skipped.

In this example the try block attempts to open a file. If the file does not exist, the handler will catch the exception and display an error message. Otherwise, the else block executes which contains code to process the file that is now known to be opened correctly.

try:
    file = open("example.txt", "r")

except FileNotFoundError:
    print("Error: The file does not exist.")

else:
    for line in file:
        print(line.strip())

    file.close()

The finally Clause

A try/except statement may include an optional finally clause, which appears after all the except clauses. The statements in a finally clause will execute regardless if an exception occurs. These are often used to perform some kind of cleanup before exiting like closing a file.

General format:

try:
    statement
    statement
    ...

except:
    statement
    statement
    ...

finally:
    statement
    statement
    ...

In this example the try block attempts to open and read the file. The except block handles the case where the file does not exist. And the finally block ensures that the file is closed if it was successfully opened.

try:
    file = open("data.txt", "r")

except FileNotFoundError:
    print("Error: The file does not exist.")

finally:
    try:
        file.close()
    except NameError:
        pass

What If an Exception Is Not Handled?

We have encountered this throughout all the previous content. Unhandled exceptions cause the program to halt and provide a default error message.

When it comes to using a try/except suite, exceptions can still go unhandled if we do not have an except clause that specifies the exception of the correct type or an exception is raised outside the try/except suite altogether.
